Project Description: E-commerce Apple Store Clone

This project is a modern React-based e-commerce application designed for purchasing Apple products, including iPhones, iPads, and Apple Watches. It provides a seamless shopping experience with interactive features, responsive design, and efficient state management.

Features:

 1. Product Browsing: Explore a curated selection of Apple devices with detailed product descriptions and images.

 2. Add to Cart and Favorites: Easily add products to your shopping cart or save them to a favorites list for later consideration.

 3. Dynamic Navigation: Intuitive and responsive navigation allows users to switch between categories effortlessly.
  
 4. Cart Management: View, update, and remove items in the cart with real-time price calculations.

 5. Responsive Design: Fully optimized for desktops, tablets, and mobile devices, ensuring a smooth user experience on all screen sizes.

 6. React Context API: Efficient global state management for features like cart and favorites without unnecessary prop drilling.
 
 7. React Router DOM: Seamless navigation across pages with dynamic routing for products and categories.
 
 8. Modern Styling with SCSS: Aesthetic and maintainable design using SCSS for component-level styling and theme customization.

 9. Classnames Utility: Clean and dynamic class management ensures consistent styling across components.

Additional Launch Instructions To launch the project locally, follow these steps:

Clone the repository from GitHub: git clone repository [link](https://github.com/andreyysak/phone-catalog.git)

Navigate to the project directory: cd [your project directory]

Install the necessary node modules: npm install

Run the project to view it in your browser: npm start
